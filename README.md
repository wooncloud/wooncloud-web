# wooncloud-web

풀스택 개발자 운구름의 개인 포트폴리오 웹사이트입니다.

🔗 **[https://wooncloud.com](https://wooncloud.com)**

## Tech Stack

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui (Radix UI)
- **Database**: Supabase
- **Icons**: Lucide React

## Features

- 프로필 및 소개
- 카테고리별 기술 스택
- 경력 사항 (Experience)
- 프로젝트 포트폴리오
- 자격증 및 학력
- 소셜 링크 (Blog, GitHub, LinkedIn)
- 연락처 페이지
